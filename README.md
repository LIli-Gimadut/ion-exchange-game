# Реакции ионного обмена (РИО)

**Играть онлайн:** <https://lili-gimadut.github.io/ion-exchange-game/>

Обучающая игра на Python/Pygame: на экране 4 пробирки. Сверху — **основная**,
снизу — 3 варианта. Перетащите (drag-and-drop) к основной тот раствор, который
даёт реакцию ионного обмена. После переливания проигрывается анимация результата:

- **газ** (пузырьки + формула газа, напр. CO₂↑),
- **осадок** (оседающие частицы + формула осадка, напр. BaSO₄↓),
- **вода** (появление H₂O при нейтрализации),
- **красный крест**, если выбран неверный вариант.

При верном ответе под основной пробиркой показывается полное молекулярное
уравнение с подсветкой продукта (осадок/газ/вода).

Игра состоит из **5 раундов**; варианты не делят с основной ни катион, ни анион
(иначе обмен заведомо не даёт нового вещества). Тип эффекта выбирается равномерно,
чтобы встречались все три анимации. После 5-го раунда — экран с результатом и
вердиктом по числу верных ответов. Любая клавиша — новая игра.

## Запуск

```bash
uv run python main.py                # игра
uv run python main.py --level 2      # разбор формулы на ионы
uv run python main.py --level 3      # сокращённое ионное уравнение
uv run python tools/gen_assets.py    # перегенерировать ассеты пробирки (SVG→PNG)
uv run python -m pytest -q           # тесты
```

## Веб-версия

GitHub Actions собирает браузерную версию через Pygbag (CPython + pygame-ce в
WebAssembly) и публикует её на GitHub Pages после каждого изменения ветки
`main`. Благодаря этому игровая и химическая логика остаётся общей для
настольной и веб-версий, без отдельной переписанной копии на JavaScript.

Управление: тащите пробирку мышью к основной, `Esc` — выход.

## Как определяется реакция

РИО считается «идущей до конца», если хотя бы один продукт обмена — **осадок**
(нерастворим по таблице растворимости, включая H₂SiO₃↓), **газ** (CO₂, SO₂, H₂S,
NH₃) или **вода** (нейтрализация H⁺+OH⁻). Логика — на основе ионов и таблицы
растворимости, поэтому «неверные» варианты гарантированно не реагируют.

Набор реагентов генерируется из таблицы растворимости: кислотные остатки
школьного курса (F, Cl, Br, I, S, SO₃, SO₄, NO₃, NO₂, CO₃, SiO₃, PO₄, OH) и
металлы ряда активности (K, Na, Ba, Ca, Mg, Al, Zn, Fe, Ni, Pb, Cu) + H⁺, NH₄⁺.
Реагентами могут быть только растворимые вещества; несуществующие и
гидролизующиеся комбинации (Al₂(CO₃)₃, Al₂S₃, CuI₂ и т.п.) исключены.

## Структура

- `chemistry/` — ионы, вещества, таблица растворимости, движок `react()` (без pygame).
- `game/` — генерация раундов, сцена/автомат, отрисовка, анимации.
- `tools/gen_assets.py` — авторская SVG-пробирка → PNG (через pygame, без системных библиотек).
- `tests/` — растворимость, движок РИО (вкл. golden-матрицу), раунды (fuzz), логика сцены.
